## 🚀 Quick Start (3 Steps)

### Step 1: Install & Run

```bash
cd darwin-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

### Step 2: Customize Your Info

Edit these 3 files with your information:

1. **`src/components/Hero.js`** - Your name and tagline
2. **`src/components/About.js`** - Your bio and stats
3. **`src/components/Contact.js`** - Your email and social links

### Step 3: Add Your Content

Create files in these folders:

- **`content/projects/`** - Add your projects (Markdown)
- **`content/blog/`** - Add your blog posts (Markdown)
