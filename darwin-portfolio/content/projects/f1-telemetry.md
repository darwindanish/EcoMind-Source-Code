# F1 Telemetry Dashboard

A real-time dashboard for visualizing Formula 1 telemetry data during races.

## Features

- Live race data streaming via WebSocket
- Interactive lap time comparisons
- Driver performance analytics
- Tire strategy visualization
- Sector time breakdowns

## Tech Stack

- **Frontend**: React, D3.js for data visualization
- **Backend**: Node.js with WebSocket support
- **Data Source**: F1 API integration

## Inspiration

As a huge Carlos Sainz fan, I wanted to build a tool that helps analyze his racing performance in real-time. This dashboard provides insights into lap times, tire degradation, and optimal pit stop windows.

## Future Improvements

- Add machine learning predictions for race outcomes
- Implement historical data comparison
